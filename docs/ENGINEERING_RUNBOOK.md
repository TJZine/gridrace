# GridRace engineering entrypoint

Start with [AGENTS.md](../AGENTS.md) and the [GridRace project profile](../.agents/project.md).

The shared develop-code, design-code, review-code and verify-code skills own general procedures. The profile owns GridRace-specific boundaries, commands, conditional local-runtime procedures and evidence selection. maintain-workflow is optional and explicitly invoked.

Current execution belongs in the applicable active task record under [plans/](plans/). Historical plans preserve evidence and do not reinstate superseded workflow policy. The [current-work index](NOW.md) is navigation only.
